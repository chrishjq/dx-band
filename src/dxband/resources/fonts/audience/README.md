# Audience subtitle fonts

The four bundled Chinese display fonts are sourced from the official Google Fonts
repository. Each font is redistributed without modification together with its own
`OFL.txt` file under the SIL Open Font License 1.1.

- Ma Shan Zheng: https://github.com/google/fonts/tree/main/ofl/mashanzheng
- Long Cang: https://github.com/google/fonts/tree/main/ofl/longcang
- ZCOOL XiaoWei: https://github.com/google/fonts/tree/main/ofl/zcoolxiaowei
- ZCOOL QingKe HuangYou: https://github.com/google/fonts/tree/main/ofl/zcoolqingkehuangyou

The formerly bundled YShi-Written and LemiShiGuangShouZhaTi fonts were removed
because their redistribution rights could not be verified. Existing saved font IDs
fall back to the system default font.
