# 控件图标来源与许可

本目录 31 个 SVG 图标由官方 `@fortawesome/fontawesome-free` 7.2.0 包中
`svgs/solid/` 的 Font Awesome Free Classic Solid 图标替换而来。
图标版权归 Fonticons, Inc. 所有；SVG 图标依据 CC BY 4.0 许可使用，
不按本项目的 GPL-3.0-only 重新授权。原始版权注释保留在各 SVG 内。

来源：https://fontawesome.com/
上游包：https://www.npmjs.com/package/@fortawesome/fontawesome-free/v/7.2.0
上游许可：https://fontawesome.com/license/free
上游许可证副本：[LICENSE.txt](LICENSE.txt)

修改：仅将每个 SVG 路径的 `fill="currentColor"` 改为界面使用的固定颜色，
以维持 Qt 图标在深色背景、强调按钮和危险操作按钮上的对比度；
几何路径保持上游原样。
